# Quiz App

A React-based quiz application using the Open Trivia Database API.

## Features
- Multiple categories (General Knowledge, Science, History, etc.)
- Three difficulty levels
- Responsive design
- Answer review after quiz
- Fast and interactive

## How to Use the App
1. Select number of questions (5-50)
2. Choose a category
3. Pick difficulty level
4. Start quiz and answer questions
5. Review your results

## Technologies that I Used
- React.js
- Open Trivia Database API
- CSS3
